# Windows upgrade gate

`installer.nsi` derives from the [Tauri CLI 2.11.4 template](https://github.com/tauri-apps/tauri/blob/tauri-cli-v2.11.4/crates/tauri-bundler/src/bundle/windows/nsis/installer.nsi), under Tauri's MIT/Apache-2.0 licensing. It is pinned to the CLI in `desktop/package.json`. When upgrading Tauri, rebase the template and verify both uninstall-first and direct-update paths. Ripple adds only the safe preflight calls, removes forced application shutdown, disables skipped extraction files, and adds reconnection guidance.

The preflight runs before the old uninstaller and again immediately before copying files. Silent installs fail with exit 20 if resources cannot safely be released; interactive installs offer Retry/Cancel. It never changes process execution policy, client configuration, credentials, proxy or file associations. PowerShell executes the shipped script in an isolated process, with paths passed as environment values rather than command text. Inspection failures stop the upgrade.

A running Ripple desktop or any non-adapter process using this installation's Python blocks installation: save work and exit normally first. This also supports upgrading b65, whose backend has no installer drain endpoint. After the desktop exits, its existing parent watcher releases the backend. Only exact `python.exe -m app.connector_mcp` processes from this installation may then be terminated; these adapters forward RPC and do not write manuscripts themselves. Their process handles and creation times are checked before termination. Other client hosts, installations and MCP services are not terminated. A client that repeatedly restarts its adapter must have only its Ripple connector temporarily disabled by the user.

Every existing installation file is checked for exclusive write access. Windows Restart Manager supplies a remaining lock owner's name/PID where available; an unknown owner still blocks replacement. The preflight is a short-term coordination measure, not a transactional installer. A new lock arriving after preflight causes NSIS to offer Retry/Cancel; Ignore is disabled. Do not claim arbitrary I/O failures have rollback guarantees.

After upgrading, open Ripple. Automatic reconnection depends on each external client. If it does not reconnect, use that client's reconnect action, re-enable its Ripple connector, or restart the client. An AI conversation cannot restore a disconnected transport by itself. Packaged adapter restart tests do not prove Claude/WorkBuddy GUI reconnection; verify those on the user's Windows installation using only a synthetic manuscript.
