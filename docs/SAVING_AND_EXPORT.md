# 保存与导出

## 保存当前稿件

编辑稿件会自动保存到当前项目；也可点击保存或按 Mac `⌘S`／Windows `Ctrl+S` 立即保存当前稿件。保存按钮不是“另存为新版本”。创建、切换和重命名编辑版本使用版本入口；原始转录稿保持只读，原稿的资料备注可独立保存。

以保存状态为准，不把画面上的修改当作已经写入磁盘。保存失败时保留当前窗口和内容，检查项目文件夹权限或磁盘状态，再重试；不要靠重新启动解决未保存内容。切换稿件、返回项目和准备更新时会检查或刷新待保存内容。AI 正在编辑目标版本时，先结束该任务并核对保存结果，再作人工修改。

## 导出单份稿件

在编辑器打开导出入口；Mac 可按 `⌘E`，Windows 可按 `Ctrl+Shift+E`。

| 格式 | 用途与边界 |
| --- | --- |
| Word（DOCX） | 可继续排版的文字稿；批注使用 Word 评论 |
| TXT／Markdown | 文字、稿件资料和批注；不保留编辑器的高亮样式 |
| PDF | 通过打印窗口预览并选择保存为 PDF；系统打印／保存结果需单独核对 |
| JSON | 导出当前转录数据；排除高亮、内部时间来源、对照审阅状态和 AI 保存回执，不是完整项目备份 |
| SRT／VTT | 需要稿件具备有效时间戳；无时间戳文字不生成虚构字幕时间 |

界面语言会影响导出字段标题和缺省说明，不翻译用户正文、说话人姓名、批注或项目名称。仅有年份或年月的资料保留该精度，不补成某月第一天。关联音频也不会自动给无时间戳稿件生成对齐关系。

## 项目页导出

项目页的导出按钮提供两种用途：

- **材料导出**：按场次、录音选择音频和具体稿件版本，为各稿件选择格式，再打包为 ZIP。默认稿件格式为 DOCX；此批量入口不提供 PDF。读取材料失败时先重试，不导出不完整清单。
- **项目副本**：保存可重新打开的 `.ripple` 文件夹，保留场次、稿件及版本、项目内音频，以及稿件的 AI 规则和续写任务记录。未完成的任务在副本中保持暂停，重开不会自动启动 AI；确认目标后再继续。无法读取的任务原文件仍随副本保留，单独提示，不阻断其他完好任务。回收站不包含在副本内；引用的外部音频只保存引用说明，重开后需定位原文件恢复播放。副本不包含本机凭据、全局偏好或第三方客户端配置。

外部音频原文件不会因导出被移动或删除。不要把项目副本称为已包含全部外部录音的完整备份；需要长期归档时，另行保存引用的原音频并核对可读取性。项目复制失败会留下未完成标记，原项目保持不变；详情见[项目与数据](projects.md)。

## 验证边界

本页预审对照当前保存、导出源码与已验 Mac 行为，不增加新的真实材料操作。自动格式／文件系统测试、系统打印窗口、导出后的文件内容和使用者验收分别记录。Windows 安装包、原生文件选择／打印与实机验收仍留到 Release 前；不能用 Mac 结果代替 Windows 已通过。完整线上升级的待验范围见[桌面更新](DESKTOP_UPDATES.md#verification-status-before-release)。

## 标签与导出范围

项目索引保存schema3标签实体，完整路径大小写不敏感唯一，跨路径可有同真名；每个转录稿／保存版本的`transcript.tagCollection`保存纳入集合和独立平级组。当前集合内真名唯一，纳入子标签同时原子验证并纳入祖先，祖先不自动赋片段或入组。`tagIds`只关联当前版本片段，移除最后一次关联仍保留纳入集合。新副本继承后独立修改，拆分继承、合并取并集；原始稿的片段标签入口只读。

共享改名／移路径预检全部已保存使用版本，包括可恢复项目回收站材料。重叠路径必须显式确认合并；冲突阻止全部变更并显示稿名与路径。实体、纳入、片段及组关联通过项目修订检查、版本目录队列、验证备份与可恢复多文件事务保存；成功前不发布UI和撤销记录。失败恢复全部相关文件，独立编辑已改变时不覆盖；中断日志在同一项目锁下恢复。撤销／重做只更新标签字段，不能恢复旧正文；与正文编辑共享准确的动作顺序。

打开旧项目不写入迁移。旧项目库升级时保留实体ID与旧分组只读快照；旧版本缺少集合时按既有实际标注、旧分组及必需祖先读取，当前版本首次明确修改后保存自己的集合，其他未打开版本不丢旧关联。旧版应用不支持schema3，回退须使用变更前完整项目副本或相应事务备份，不把新版项目直接交给旧版继续写入。事务备份保存在项目内`.ripple-tag-backups`，不加入普通稿件导出。

分级“当前稿”只移除本版本使用：叶单独移出，有本稿后代的父标签连同本稿分支，清除对应片段和组关系，不改变项目路径或其他版本，不自动清理未选中的零命中祖先。“项目”范围才删除实体：删除标签让孩子提升一级，删除分支包含后代；影响所有使用版本，正文和录音不删除。均先选择动作再确认，可在当前会话撤销；重开不承诺保留撤销栈。分组解散只删本稿组结构／成员关系。

分级徽标仅显示当前版本命中片段数，无分母和数量排序；父级自身与后代按片段去重，两库范围使用同一计数，分组不显示数字。导出第一步只选完整稿／当前显示片段数，第二步替换为既有Word、TXT、PDF、JSON、SRT、VTT、Markdown格式与返回。范围始终当前版本；当前显示取标签AND／OR与说话人等过滤交集的全部片段，和viewport无关；零结果不回退全文。人读文件的原编号在时间戳后半角括号，不在说话人前。字幕保留自身cue编号及原时间起止；JSON的`sourceSegmentNumber`记录原编号，剥离内部集合与标签ID。

第二步格式下方的其他项目文件入口与当前片段过滤独立。项目副本保留完整目录与历史版本，整段复制／拖出仍是指定片段，深链接格式不变。本轮不提供标签库导入／导出。
