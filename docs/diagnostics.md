# 诊断与日志

入口：设置 → 诊断与日志。

- 查看近期问题的时间、操作、错误分类；可复制单条详情。
- 导出 JSON 诊断文件，包含 Ripple 版本、系统/浏览器类别、本机问题及后台请求失败状态。
- 不自动上传；诊断记录不包含文件名、密钥、音频、文稿、请求正文或服务商原始报错。
- 界面与后台分别限制为 100 条，读取/写入时清理超过 7 天的记录。界面相同分类在 5 秒内连续出现时合并计数。
- 后台不可用时仍可查看/导出界面记录；磁盘或浏览器存储不可写时尽量保留本次运行中的记录并说明限制。

界面记录保存在当前浏览器的本机存储 `ripple-diagnostics-v1`；后台记录在 `backend/.logs/diagnostics.json`。既有开发日志 `.logs/backend.log` 不读取、不打包，它不属于此脱敏诊断文件。独立 App 的日志目录与“打开日志文件夹”按钮留待封装时实现。

接入的错误路径：打开文稿、保存、重命名、转录、导入、导出、版本操作、AI 编辑、引擎设置、对照读取，以及未处理的界面异常；后台记录失败请求的操作分类和 HTTP 状态。诊断文件仅提供排查线索，不保证还原每个故障的完整原因。

验证（2026-09-21）：前端全套 450 项通过；最后的保留期清理及界面调整后，相关 33 项复测及构建通过；后端 256 项通过。浏览器实查设置页布局、空状态和刷新后“后台记录已更新”。复制失败与导出文件内容通过组件测试验证，未以真实用户故障进行端到端验收。

### AI 编辑耗时

前端记录每次生成的随机运行编号、阶段、结束时间、持续毫秒数、批次或完成批数、片段数和字符数，以及完成/失败/取消状态。记录保存在本机浏览器，按最后活动时间保留最近 7 天最多 20 次运行，按整次运行淘汰，保留其全部已记录阶段。旧版本已被截断的阶段不能恢复。设置中的“AI 编辑耗时”显示最近一次运行，导出诊断信息包含保留的全部阶段记录。存储不可用时退回本窗口内存。

请求计时为浏览器到本机后台及模型服务的整个往返，不代表纯模型推理时间；并发请求不可直接相加。保存进度计时包括草稿持久化队列内的等待和实际写入，不包含批次调度器在调用该保存回调前的等待。总耗时覆盖准备、并行生成、保存进度、最终结果保存和生成新版本。计时不保存文稿、文件名、密钥、模型响应或异常文本，也不新增模型请求。

### 字数分批与断点续做

新任务以 3000 字符为目标分批，不拆分片段；单个 3000–6000 字符的片段单独处理，超过 6000 字符仍要求人工拆分。128 段为兜底上限，同时最多两批请求。后端保留每批 6000 字符的硬性校验。

草稿保存原分批编号和每批完整结果（包含未改片段），与已有原稿快照及请求设置绑定。续做只发送缺失批次，保留原批次边界；修改原稿、范围、规则、偏好、引擎或模型地址/名称后不能混合续做。模型配置指纹只含地址和模型，不包含密钥。失败不会自动重试，用户手动选择“继续未完成部分”。旧版只有修改建议的草稿无法安全判断完成批次，保留原记录但要求重新生成。

后台诊断新增允许列表内的失败分类：连接/读取/写入/连接池超时、代理连接失败、连接建立失败、响应连接中断或协议异常、发送失败、上游 HTTP 错误、输出长度截断、格式错误等。分类不包含异常原文或上游响应正文。

## 转录计时与连接恢复

转录计时按一次前台操作记录准备、读取并提交音频、可观察到的云端上传、等待结果和本地保存；恢复前的等待时间保留在先前操作记录中。没有独立上传进度的引擎，其云端上传耗时包含在等待结果中。仅记录随机编号、时间、阶段时长与状态，不包含文件名、正文、任务令牌或密钥。最近 7 天最多 20 次转录操作，随诊断导出；界面默认只显示最近一次摘要。

新增后台任务模式适用于现有全部转录引擎：请求交给本地后台后，断开浏览器或停止等待不会主动取消后台任务。音频旁的隐藏 `.音频文件名.ripple-job.json` 保存随机任务编号及文件/选项匹配信息。再次以相同音频和选项开始时，优先查询原任务；结果成功保存后释放恢复记录。任务记录及完整结果仅暂存在后台内存，最多 20 个，完成任务 24 小时后可被清理。后台重启会丢失恢复能力；不自动重新提交，必须由用户明确选择重试。客户端没有上传完成前，不能恢复上传字节进度。

这不是音频分块断点续传，也尚未接入云端任务编号的持久化恢复。讯飞普通/大模型和腾讯标准/URL 代码内部有上传后任务查询；ElevenLabs、OpenAI 兼容及腾讯极速是单次请求，FunASR 为 WebSocket 流程。本轮不更改各引擎协议，不拆分音频。真实服务与重启后云端恢复仍需分别验收。
