# Ripple Stylebook

**现行界面规则 · 2026-09-29 源码核对**

本文件供修改 Ripple 界面的人使用。它记录当前产品的界面角色和交互约束；具体数值以所链接的现行源码为准。本次核对了源码，没有因此重新完成浏览器、打包或已安装桌面版验收。私人审阅过程、截图和历史验收记录不在本公开文档中。

## 如何维护

- 修改布局、可见文案、按钮或菜单、状态提示、焦点、快捷键、播放或版本展示时，先读相关章节；纯内部改动无需通读。
- 最终做法改变了现行规则或增加了新规则时，更新对应条目和实现链接；规则未变时无需改写本文件。
- 核对源码与相关测试，并分别记录浏览器、构建、桌面安装版和用户验收的证据。源码中的实现不能单独证明原生体验。
- 产品含义与用户数据边界应先明确，再决定视觉参数。历史记录和其他产品的尺寸、颜色不自动成为 Ripple 的要求。

## 产品气质与信息层级

| ID | 规则 | 检查方式 |
| --- | --- | --- |
| R01 | 内容优先 | 项目页先辨认项目、场次和材料；编辑页先辨认当前文稿、版本、说话人与时间。 |
| R02 | 身份按对象分层 | 项目名、场次名、音频或文稿来源、版本名各说明自己的对象；改名提示准确说明影响范围。 |
| R03 | 操作入口稳定 | 顶栏承载导航与全局操作；材料和片段的局部操作贴近对象。常用动作可发现。 |
| R04 | 显示装饰不改原文 | 播放跟随、查找高亮、版本比较标记和折叠状态不得写入转录正文或导出文本。 |

应用标志使用纸张版 Ripple Logo，Finder 项目图标使用对应纸张版文件夹图标；不另加底板。macOS 系统应用图标在 1024px 透明画布中使用居中的 840×840px 可见主体（以 alpha > 16/255 测量），将原画底板的宽高分别归一化，并检查最终栅格与各 ICNS 分辨率。这是依据常规应用图标实测确定的 Ripple 参数，不是 Apple 强制比例；原始 PNG、应用内标志与项目文件夹图标保留原比例与边距。日用版必须使用正式构建模式，使 Dock 与 Launchpad 共用包内 ICNS，不以开发模式内嵌 PNG 覆盖 Dock 图标。更换日用版图标时，若固定的 Dock 条目仍显示旧资源，只刷新 Ripple 条目的缓存标识并备份原条目，保留其他应用和排列。项目仍是普通文件夹；图标设置失败不阻断项目操作，并给出可写权限与重开提示。

Ripple 使用暖纸白表面与蓝青品牌色，深色播放器是独立功能区，不表示整套深色主题。项目、场次、材料、转录片段和版本形成不同层级。实现入口见[全局样式](../frontend/src/styles.css)、[项目工作区](../frontend/src/components/ProjectWorkspace.tsx)和[编辑器](../frontend/src/App.tsx)。

## 视觉角色

以下是源码中的角色，新增界面优先使用变量而非复制颜色值；局部组件允许有明确用途的例外。

| 角色 | 当前变量或字体 | 用途 |
| --- | --- | --- |
| 页面与内容 | `--color-page-bg`, `--color-surface-warm` | 外围暖白与阅读表面 |
| 主要与次级文字 | `--color-text`, `--color-text-3` | 内容与辅助说明；重要说明不能靠低对比度隐藏 |
| 主操作与焦点 | `--color-accent`, `--color-focus` | 蓝青操作、键盘定位 |
| 删除与错误 | `--color-danger` | 破坏性操作及失败，配明确文字 |
| 播放器 | `--color-player-bg` | 独立的深色播放区域 |
| 播放与手工标记 | `--color-playback`, `--color-highlight` | 两种含义必须能区分 |
| 界面与正文 | `--font-sans`, `--font-transcript` | 控件与转录正文分别定义 |
| 品牌与项目标题 | `--font-serif` | 标题角色，不推广到普通控件 |

当前变量、间距和圆角定义见[全局样式开头](../frontend/src/styles.css)。普通控件的键盘焦点应可见；局部编辑器可采用专门焦点样式，但不能让键盘位置不可辨认。勾选框沿用 `ripple-checkbox` 的原生控件与品牌强调色。

| ID | 规则 | 检查方式 |
| --- | --- | --- |
| R05 | 普通菜单文字使用 `--font-sans`、`0.86rem`、字重 `400` 和正常行高；图标按钮的字号、字重不得传给菜单选项。选中状态使用勾选或明确标志表达。语言选择使用与导出同类的应用内菜单，单击展开，支持方向键与 Esc，避免透明原生 select 覆盖图标。 | 检查展开后的中文、英文选项，与同级菜单对照；系统原生菜单另在桌面窗口核验。 |
| R06 | 时钟、语言地球、设置、项目回收站和导出操作共用统一偏细图标：20px 占位，屏幕实际笔画 1.25px，最长可见轮廓约 15.5px。按原图案边界校准视口与笔画，保留原图案、颜色和按钮外框；欢迎页按钮为 44px，项目／编辑器同类按钮沿用各自外框。上述图标不再叠加全局 SVG 内留白或语言图标专用放大规则。其他按钮 SVG 沿用四周 1px 内留白；品牌标志及按钮外的对象、说明图标保留原比例。 | 在中英文界面对照时钟与地球、设置与语言、回收站与导出，检查默认、展开、选中、悬停、键盘焦点和适用的禁用状态；用实际绘制范围和计算样式确认笔画及占比。实现见[统一操作图标](../frontend/src/components/ActionIcon.tsx)与[全局样式](../frontend/src/styles.css)。 |

Ripple 提供的原生菜单名称随界面语言切换，保留原生动作和快捷键；macOS 自动追加的菜单项及服务名称由系统管理。原生浮层的字体、间距、焦点和选中标记须在桌面展开核验。实现见[原生菜单语言同步](../frontend/src/lib/nativeMenu.ts)与[原生菜单](../desktop/src-tauri/src/native_menu.rs)。

语言切换的“简体中文”和“English”是普通菜单选项。透明覆盖在地球图标上的原生 `select` 仍需明确设置文字样式，并保留系统选择、键盘操作和可辨焦点。实现见[语言菜单样式](../frontend/src/components/languageControl.css)与[普通菜单样式](../frontend/src/styles.css)。源码或 DOM 中的字体值不能单独证明系统弹出菜单的实际外观。

## 状态与反馈

| ID | 规则 | 检查方式 |
| --- | --- | --- |
| R10 | 悬停、焦点和已生效值分开 | 鼠标离开后悬停消失；当前值有持续可见的选中、勾选或文字标志；键盘焦点仍可见。 |
| R11 | 只让最上层弹窗接受操作 | Tab 留在当前弹窗，Escape 取消当前层，关闭后焦点回到触发位置。 |
| R12 | 禁用说明前置条件 | 操作真正不可执行；需要时就近说明如何继续。 |
| R13 | 进度真实 | 有实际比例才显示百分比；等待识别或模型请求时显示阶段，不编造进度。 |
| R14 | 错误给出下一步 | 说明失败对象、重试或恢复入口；原始技术信息放诊断或复制问题入口。 |
| R15 | 反馈寿命符合状态 | 短暂成功提示可消退；进行中随任务更新；失败和待处理状态保留到用户处理或明确关闭。 |

键盘焦点按控件含义表达，普通外框统一为 1px 品牌色：

| 场景 | 焦点表示 |
| --- | --- |
| 鼠标点击普通按钮 | 使用悬停或按下反馈，不额外显示键盘外框。 |
| 键盘到达普通按钮、独立开关或多选框 | 细外框；多选时保留勾选，焦点标明当前键盘位置。 |
| 单选项 | 圆形点表示选择，文字下的细虚线表示键盘位置，不在圆点外再套方框。 |
| 当前标签页、当前场次、当前版本 | 利用底部线或场次侧线表达；标签页焦点使用细虚线，版本焦点使用底部细线，不重复套框。焦点落在非当前项时仍有细框。 |
| 文字编辑 | 使用控件自己的细边线或下划线，避免叠加第二层外框。 |

材料删除弹窗先聚焦安全的取消操作；单选控件保留原生输入语义，使用固定圆形外观、独立列和文字间距，长文字换行不能挤压圆点。项目恢复提示的说明在上、操作按钮在下方靠右，中英文使用统一应用字体，窄窗允许操作行换行。系统绘制的原生菜单仍需桌面检查。

参考[设置弹窗](../frontend/src/components/SettingsModal.tsx)、[持久化状态](../frontend/src/hooks/usePersistence.ts)和[诊断入口](../frontend/src/lib/diagnostics.ts)。提示文案保持简短并靠近影响的对象；完整规则与例外放产品文档，不塞入悬浮提示。

## 转录、音频与版本

| ID | 规则 | 检查方式 |
| --- | --- | --- |
| R30 | 说话人身份与片段位置可辨 | 名称与颜色共同表达；同一阅读栏的片段正文左边缘对齐，长名字不挤压正文；相近颜色及窄栏仍能读清。批注数量位于片段序号左侧；序号使用同宽列并左对齐，有无批注和数量变化均不移动序号。 |
| R31 | 当前片段与正在播放分开 | 选择、播放跟随、查找匹配和手工高亮各有含义；暂停或切换后清除播放装饰，不删除用户标记。 |
| R32 | 原稿只读、编辑稿可修订 | 版本身份可见；项目管理页与编辑器应列出相同的用户版本，名称同步，打开时指向所选版本；版本组以原稿或最早保留的编辑稿为上级，后续版本缩进列出，层级不随当前激活版本改变；AI 生成结果不等于用户已认可内容。 |
| R33 | 修改痕迹只作比较 | 对照版本、接受或拒绝、隐藏标记是不同操作；比较装饰不进入正文或导出。 |
| R34 | 离线音频仍保留文稿 | 文稿可读、可编辑；无法播放时说明音频问题并提供重新关联路径。 |

独立导入稿只有被指定为原稿时才显示为只读原稿。内部导入快照可用于来源与时间定位恢复，不作为当前/对照菜单或 MCP 的普通候选版本，也不自动解释为人工编辑偏好的基准。快照用途保留在产品文档，不在版本菜单显示内部机制说明；快照不删除、不改写为用户版本。

实现入口见[片段组件](../frontend/src/components/SegmentItem.tsx)、[播放跟随](../frontend/src/lib/playbackHighlight.ts)、[版本比较](../frontend/src/hooks/useVersionComparison.ts)和[项目存储](../frontend/src/lib/projectStore.ts)。涉及状态重叠时，应检查播放、查找、批注、手工高亮和比较同时出现的场景。

外部文件拖放在所有页面均不得导航或替换应用界面；只有有效且可用的导入区域执行导入。禁用区域和区域外落点不导入，内部排序继续使用自己的拖放处理。应用入口安装[全局文件拖放保护](../frontend/src/lib/fileDropGuard.ts)。

引用音频读取失败时区分权限需要恢复、原文件缺失、内容改变和其他读取失败；转录稿继续可用。恢复入口沿用音频卡片的文件夹按钮，复制到项目内的音频仍提示检查项目访问。桌面端保存用户明确选择过的资源授权，重启恢复前核对文件身份，失效授权不得访问替换到原路径的其他资源。

最近项目在桌面授权有效时直接打开；失效、缺失或读取失败时显示对应原因，由用户点击“重新选择原项目”恢复，也可取消。恢复后核对项目身份，不能把另一个项目替换到原最近项。

## 保存、删除与导出

| ID | 规则 | 检查方式 |
| --- | --- | --- |
| R40 | 保存失败保留工作 | 自动保存、手动保存、切换文稿和关闭窗口都要保留未成功写入的内容与重试路径。 |
| R41 | 删除准确指向对象 | 移入项目回收站、永久清空、删除版本和外部音频引用应分别说明影响；永久删除有可取消的确认。 |
| R42 | 导出准确指向范围 | 单稿文件导出、所选版本的项目材料包和完整项目副本是不同结果。材料包按项目／场次／音频转录稿组合分层，并包含所选版本与可读取的引用音频；不提供 PDF 批量导出，提示用户在编辑器中逐稿导出 PDF。 |
| R43 | 复制与引用音频可区分 | 选择“引用原文件”后，失效或重新选择的说明贴近该选项，不让用户误以为音频已复制进项目。 |

## 窗口、语言与验证范围

- 编辑页在较窄窗口采用独立布局；当前 CSS 在 919px 以下将编辑页最小宽度设为 540px。非编辑页仍有不同的最小宽度与断点，不能把编辑页结果推广到所有页面（[全局样式](../frontend/src/styles.css)、[项目样式](../frontend/src/components/projectWorkspace.css)）。
- 页面缩小时先保护转录正文和必要操作的可见性，再调整侧栏、标题和工具栏。检查长中文、长英文、低窗口高度、四种侧栏组合与弹窗叠加。
- 界面文案的中英文维护按[文案规则](i18n/AUTHORING.md)进行；切换语言只影响界面，不改项目名、转录稿、用户规则或模型输出。
- 浏览器、自动测试、构建、macOS/Windows 打包和已安装桌面版操作分别记录。此文档的源码核对不代表上述平台已完成新一轮验收（[开发流程](WORKFLOW.md)）。

## 外部 AI 连接

所选 AI 软件的“删除 ChatGPT／Claude／WorkBuddy 连接配置”使用危险色的文字按钮，与启停分开。确认框明确软件名称与本机配置／凭据范围，先聚焦取消，Esc 只取消最上层确认，关闭后回到触发按钮；删除成功后该按钮消失，焦点回到软件选择框。删除期间锁定操作；进行中的该软件请求先结束再删除，失败留在确认框并可重试，不回显原始错误或凭据。删除保留其他软件、项目、稿件和下载的连接程序；远端隧道／密钥撤销及其他软件插件卸载在对应软件／网页处理。成功重置 ChatGPT 表单并提供重新添加路径，不重启其他软件的连接。

“AI 辅助编辑”标签页只包含“MCP 连接”。说明先介绍读取、分析、经用户选择另存新版本或修改当前可编辑版本，以及在当前版本添加批注与高亮；启用开关不附带实现细节，访问范围紧随能力说明，直接表述当前项目文稿，不增设范围选择器。未指定精确版本时 AI 列候选并询问，不默认最新或激活版本；后台编辑不切换正在打开的稿件，保存通知写明目标稿件与版本。后台分批进度使用同一紧凑提示并标明目标，暂停、继续、结束和提案查看按该任务操作；后台版本没有当前编辑器的撤销历史，另存版本用于持久对照。取消启用即断开，不另设重复的“断开连接”按钮。首次明确开启后保存选择，重启自动恢复，主动关闭同样保存；切换当前访谈无需重新授权。

MCP 区域复用凭据卡的字号：标题和文本输入为 .84rem，下拉选择器与服务商选择器一致为 .78rem，标签、说明、状态、按钮及折叠标题为 .78rem；不再增加更小的说明文字层级，以颜色和间距区分用途。连接配置复用转录引擎凭据编辑卡：卡内 10px × 12px 留白，左侧 130px 标签、右侧输入和操作，字段之间 8px、标签与控件之间 10px，底部统一操作栏；窄屏字段改为单列。说明紧随对应控件，链接使用品牌色及可辨键盘焦点。本机连接面向用户提供 AI 软件选择、对应步骤、状态及启用勾选框，首批为 ChatGPT、Claude 桌面版（中文版标注“实验性”，英文版标注“beta”）、WorkBuddy。各软件在选择列表中明确标注“已配置／未配置”，只表示本机配置，不声称外部账号已连接；自动生成的凭据不算配置。未配置或状态无法核实时不显示删除入口，成功添加或删除即时更新标识。保存配置查看选择；切换不停止其他已配置连接，MCP 总开关统一控制连接启停，各自配置保留。ChatGPT 个人连接采用独立的单列四步指引：隧道标识、连接程序、连接密钥、添加到 ChatGPT；对应链接紧随步骤，密钥不回显。打开配置时查询官方 GitHub 最新正式发布信息，按本机系统和芯片匹配完整压缩包，成功状态采用三行紧凑提示：本机信息旁放轻量重新检查，完整文件名链接明确标注下载，下一行说明解压后选择哪个程序；官方最新页仅在获取失败或无匹配时显示，避免同时提供两个下载主入口。不推荐 runtime 子包，不自动下载或替换已选程序。查询有超时和重试入口，失败或无匹配时保留官方最新下载页，不将旧推荐写成最新；Mac 运行授权提示放在第二步，重名与旧隧道提示放在第四步，AI 协助设置请求可展开复制。前三步保存后，需等待实际隧道就绪才能打开 ChatGPT 添加入口；Claude 的“添加到 Claude”生成本机扩展并打开官方安装界面，由用户确认安装；WorkBuddy 的“添加到 WorkBuddy”经确认后自动备份并合并本机配置，保留其他连接，坏配置不覆盖，说明给出完整启用入口并明确启用后直接对话使用、无需从“＋”菜单选择；ChatGPT 的“前往 ChatGPT 添加”打开网页添加入口并提供复制隧道标识，仍由用户完成添加。均不复制凭据值；取消不报成功，配置添加或安装界面打开不等于 AI 已连接，移动 App 后需重新添加；不调用公共配对服务。“本机就绪”与真实 AI 接入分别说明，不宣称账号或客户端已连接。连接能力以外部 AI 表述，各客户端兼容性需分别验证。外部 AI 承担风格和范围对话；文字修改前须询问用户保存方式，已有明确选择不重复询问：另存新版本时打开正常编辑器对照；修改当前可编辑版本时保持版本名称、ID 和数量，整批修改支持当前编辑会话中的普通撤销，不承诺重启后保留该撤销历史。只读原稿不能直接修改，未选择保存方式不开始修改。批注和高亮直接添加到当前可编辑版本，保留人工标记、支持撤销，不为标记另建版本；AI 创建的批注显示“AI 批注”。设备凭据由桌面端保存在受保护的应用数据中，不传到设置界面。启停、未就绪、失败状态有明确文字；本机窗口就绪与外部连接就绪分别检查。完整使用规则见 [MCP connection](AI_CONNECTOR.md)。 长稿 AI 辅助编辑按短批次保存到同一目标版本；紧凑的进度提示固定在正文滚动区之外，不随正文滚走，也不放入限高的标题区。只显示一项当前进度并原位更新批次和已保存片段数据，当前版本的未完成任务优先，其余可恢复任务优先于历史完成任务，不堆积历史汇报或重复完成卡；其他版本的已完成任务不带入当前版本。本机任务和恢复数据仍保留。批次数来自保存回执，旧任务的批次历史不完整时不编造批次数或百分比。运行中用现有危险色的细侧线和文字提醒谨慎手动修改；标题为“AI 辅助编辑”，结束按钮为“结束编辑”，对应英文为“AI-assisted editing”和“End editing”。窄窗允许按钮换行，待提交正文在提示内限高滚动，不遮挡稿件。只有磁盘保存成功才显示“已保存”。任务和待提交结果保存在本机当前稿件内，重开后可继续；暂停、结束和重读有明确动作，结束不回滚已保存批次。人工修改其他位置继续保留，重叠正文、说话人、标记或结构变化时暂停该批并保留双方结果。每批支持本会话内普通撤销，恢复任务不自动启动外部 AI，也不扩大到其他项目；同项目后台任务按固定稿件与版本 ID 恢复，不要求先打开它。
