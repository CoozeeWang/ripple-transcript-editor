# Ripple Stylebook

**现行界面规则 · 2026-09-29 源码核对**

本文件供修改 Ripple 界面的人使用。它记录当前产品的界面角色和交互约束；具体数值以所链接的现行源码为准。本次核对了源码，没有因此重新完成浏览器、打包或已安装桌面版验收。私人审阅过程、截图和历史验收记录不在本公开文档中。

## 如何维护

- 修改布局、可见文案、按钮或菜单、状态提示、焦点、快捷键、播放或版本展示时，先读相关章节；纯内部改动无需通读。
- 最终做法改变了现行规则或增加了新规则时，更新对应条目和实现链接；规则未变时无需改写本文件。
- 核对源码与相关测试，并分别记录浏览器、构建、桌面安装版和用户验收的证据。源码中的实现不能单独证明原生体验。
- 产品含义与用户数据边界应先明确，再决定视觉参数。历史记录和其他产品的尺寸、颜色不自动成为 Ripple 的要求。

## 产品气质与信息层级

| ID | 规则 | 检查方式 |
| --- | --- | --- |
| R01 | 内容优先 | 项目页先辨认项目、场次和材料；编辑页先辨认当前文稿、版本、说话人与时间。 |
| R02 | 身份按对象分层 | 项目名、场次名、音频或文稿来源、版本名各说明自己的对象；改名提示准确说明影响范围。 |
| R03 | 操作入口稳定 | 顶栏承载导航与全局操作；材料和片段的局部操作贴近对象。常用动作可发现。 |
| R04 | 显示装饰不改原文 | 播放跟随、查找高亮、版本比较标记和折叠状态不得写入转录正文或导出文本。 |

应用标志使用纸张版 Ripple Logo，Finder 项目图标使用对应纸张版文件夹图标；不另加底板。macOS 系统应用图标在 1024px 透明画布中使用居中的 840×840px 可见主体（以 alpha > 16/255 测量），将原画底板的宽高分别归一化，并检查最终栅格与各 ICNS 分辨率。这是依据常规应用图标实测确定的 Ripple 参数，不是 Apple 强制比例；原始 PNG、应用内标志与项目文件夹图标保留原比例与边距。日用版必须使用正式构建模式，使 Dock 与 Launchpad 共用包内 ICNS，不以开发模式内嵌 PNG 覆盖 Dock 图标。更换日用版图标时，若固定的 Dock 条目仍显示旧资源，只刷新 Ripple 条目的缓存标识并备份原条目，保留其他应用和排列。项目仍是普通文件夹；图标设置失败不阻断项目操作，并给出可写权限与重开提示。

Ripple 使用暖纸白表面与蓝青品牌色，深色播放器是独立功能区，不表示整套深色主题。项目、场次、材料、转录片段和版本形成不同层级。实现入口见[全局样式](../frontend/src/styles.css)、[项目工作区](../frontend/src/components/ProjectWorkspace.tsx)和[编辑器](../frontend/src/App.tsx)。

## 视觉角色

以下是源码中的角色，新增界面优先使用变量而非复制颜色值；局部组件允许有明确用途的例外。

| 角色 | 当前变量或字体 | 用途 |
| --- | --- | --- |
| 页面与内容 | `--color-page-bg`, `--color-surface-warm` | 外围暖白与阅读表面 |
| 主要与次级文字 | `--color-text`, `--color-text-3` | 内容与辅助说明；重要说明不能靠低对比度隐藏 |
| 主操作与焦点 | `--color-accent`, `--color-focus` | 蓝青操作、键盘定位 |
| 删除与错误 | `--color-danger` | 破坏性操作及失败，配明确文字 |
| 播放器 | `--color-player-bg` | 独立的深色播放区域 |
| 播放与手工标记 | `--color-playback`, `--color-highlight` | 两种含义必须能区分 |
| 界面与正文 | `--font-sans`, `--font-transcript` | 控件与转录正文分别定义 |
| 品牌与项目标题 | `--font-serif` | 标题角色，不推广到普通控件 |

当前变量、间距和圆角定义见[全局样式开头](../frontend/src/styles.css)。普通控件的键盘焦点应可见；局部编辑器可采用专门焦点样式，但不能让键盘位置不可辨认。勾选框沿用 `ripple-checkbox` 的原生控件与品牌强调色。

| ID | 规则 | 检查方式 |
| --- | --- | --- |
| R05 | 普通菜单文字使用 `--font-sans`、`0.86rem`、字重 `400` 和正常行高；图标按钮的字号、字重不得传给菜单选项。选中状态使用勾选或明确标志表达。语言选择使用与导出同类的应用内菜单，单击展开，支持方向键与 Esc，避免透明原生 select 覆盖图标。 | 检查展开后的中文、英文选项，与同级菜单对照；系统原生菜单另在桌面窗口核验。 |
| R06 | 时钟、语言地球、设置、项目回收站和导出操作共用统一偏细图标：20px 占位，屏幕实际笔画 1.25px，最长可见轮廓约 15.5px。按原图案边界校准视口与笔画，保留原图案、颜色和按钮外框；欢迎页按钮为 44px，项目／编辑器同类按钮沿用各自外框。上述图标不再叠加全局 SVG 内留白或语言图标专用放大规则。其他按钮 SVG 沿用四周 1px 内留白；品牌标志及按钮外的对象、说明图标保留原比例。 | 在中英文界面对照时钟与地球、设置与语言、回收站与导出，检查默认、展开、选中、悬停、键盘焦点和适用的禁用状态；用实际绘制范围和计算样式确认笔画及占比。实现见[统一操作图标](../frontend/src/components/ActionIcon.tsx)与[全局样式](../frontend/src/styles.css)。 |

Ripple 提供的原生菜单名称随界面语言切换，保留原生动作和快捷键；macOS 自动追加的菜单项及服务名称由系统管理。文件菜单提供“打开项目…”和“最近项目”：前者使用 Cmd+O／Ctrl+O，后者与欢迎页共用本机最近项目列表。切换项目须遵守保存和任务限制。原生浮层的字体、间距、焦点和选中标记须在桌面展开核验。实现见[原生菜单语言同步](../frontend/src/lib/nativeMenu.ts)与[原生菜单](../desktop/src-tauri/src/native_menu.rs)。

语言切换的“简体中文”“繁體中文（台灣）”和“English”是普通菜单选项，使用各语言自称。繁中采用台湾用语，Mac 的 Help／Minimize 使用“輔助說明／縮到最小”，Windows 使用“說明／最小化”。透明覆盖在地球图标上的原生 `select` 仍需明确设置文字样式，并保留系统选择、键盘操作和可辨焦点。实现见[语言菜单样式](../frontend/src/components/languageControl.css)与[普通菜单样式](../frontend/src/styles.css)。源码或 DOM 中的字体值不能单独证明系统弹出菜单的实际外观。

## 状态与反馈

| ID | 规则 | 检查方式 |
| --- | --- | --- |
| R10 | 悬停、焦点和已生效值分开 | 鼠标离开后悬停消失；当前值有持续可见的选中、勾选或文字标志；键盘焦点仍可见。 |
| R11 | 只让最上层弹窗接受操作 | Tab 留在当前弹窗，Escape 取消当前层，关闭后焦点回到触发位置。 |
| R12 | 禁用说明前置条件 | 操作真正不可执行；需要时就近说明如何继续。 |
| R13 | 进度真实 | 有实际比例才显示百分比；等待识别或模型请求时显示阶段，不编造进度。ElevenLabs 上传以请求体发送完成为切换依据，缺少进度不推定已上传；仅有阶段信号时不显示百分比。同步接口的“转录中”表示发送完成后等待结果，不声称已获知服务内部识别开始时刻。 |
| R14 | 错误给出下一步 | 说明失败对象、重试或恢复入口；原始技术信息放诊断或复制问题入口。 |
| R15 | 反馈寿命符合状态 | 短成功反馈默认 4 秒消退并可关闭；复制错误详情的成功反馈在原按钮内显示勾号及“已复制”（纯图标模式原位显示勾号），预留切换前后宽度，4 秒后恢复，无需独立关闭控件，并通过 status 播报。重复触发重新计时，新任务清除旧成功提示，旧计时不影响新反馈。进行中随任务更新；失败和待处理状态保留到用户处理或明确关闭。 |

可关闭提示的正文在左侧换行，关闭按钮固定在右侧的同一布局行，长文件名和多段正文不能把关闭按钮挤到单独一行。已完成的材料导入说明（如只保留正文、缺少时间码）适用 4 秒反馈规则；关闭或消退只隐藏说明，不改变导入结果。保存成功和项目操作完成提示也可手动关闭；进行中的保存、转录、导入与需要重试、恢复、授权或确认的提示继续保留。AI 完成反馈的消退仅影响显示，不删除任务记录或解除尚有请求的编辑保护。

键盘焦点按控件含义表达，普通外框统一为 1px 品牌色：

| 场景 | 焦点表示 |
| --- | --- |
| 鼠标点击普通按钮 | 使用悬停或按下反馈，不额外显示键盘外框。 |
| 键盘到达普通按钮、独立开关或多选框 | 细外框；多选时保留勾选，焦点标明当前键盘位置。 |
| 单选项 | 圆形点表示选择，文字下的细虚线表示键盘位置，不在圆点外再套方框。 |
| 当前标签页、当前场次、当前版本 | 利用底部线或场次侧线表达；标签页焦点使用细虚线，版本焦点使用底部细线，不重复套框。焦点落在非当前项时仍有细框。 |
| 文字编辑 | 使用控件自己的细边线或下划线，避免叠加第二层外框。 |

配置错误保留具体文字和固定的就近显示位置，不自动聚焦、滚动或添加专用外框；普通控件的键盘焦点样式保留。取消编辑后焦点返回“修改配置”。

材料删除弹窗先聚焦安全的取消操作；单选控件保留原生输入语义，使用固定圆形外观、独立列和文字间距，长文字换行不能挤压圆点。项目恢复提示的说明在上、操作按钮在下方靠右，中英文使用统一应用字体，窄窗允许操作行换行。系统绘制的原生菜单仍需桌面检查。

载入片段数、版本切换、转录完成、AI 保存、名称同步和迁移等顶部成功提示均适用 R15。短提示归属其页面和对象：离开页面或切换场次、音频、版本时清除旧反馈，旧页面迟到的查询和成功反馈不得覆盖新页面；写入失败仍须保留诊断和未保存保护。编辑进度查询失败只在编辑页显示，正文左侧、刷新和关闭同排靠右；恢复日志损坏仍保留恢复入口，并随所属项目显示，不能出现在其他项目中。删除后的撤销提示离开页面即隐藏，已删除材料仍可从项目回收站恢复。已完成的 AI 提示仅在编辑页显示，不带到项目页或欢迎页；离开编辑页不删除任务记录，后台进行中的任务与错误／恢复提示仍保留。已完成的 AI 提示可关闭，任务记录、恢复信息、已保存内容与撤销保持；关闭不能结束正在进行的任务或解除编辑锁。连接添加后仍需授权的说明保留行动及关闭方式，输出位置等有用结果可保留。实现见[反馈计时](../frontend/src/hooks/useTransientState.ts)与[反馈关闭控件](../frontend/src/components/FeedbackNotice.tsx)。

诊断详情和导出的环境信息使用产品版本配置，不能使用前端工程包的独立版本号。转录时只用当前音频已确认的时长核对所选引擎上限；已确认超限时，在上传及文稿写入前阻止提交，说明当前时长、上限及切分或换引擎的下一步。时长未知不推断超限，也不使用其他音频或稿件中的时长。解码失败与转换建议分开显示，不重复同一句主错误与建议。

参考[设置弹窗](../frontend/src/components/SettingsModal.tsx)、[持久化状态](../frontend/src/hooks/usePersistence.ts)和[诊断入口](../frontend/src/lib/diagnostics.ts)。提示文案保持简短并靠近影响的对象；完整规则与例外放产品文档，不塞入悬浮提示。

## 转录、音频与版本

| ID | 规则 | 检查方式 |
| --- | --- | --- |
| R30 | 说话人身份与片段位置可辨 | 名称与颜色共同表达；同一阅读栏的片段正文左边缘对齐，长名字不挤压正文；相近颜色及窄栏仍能读清。批注数量位于片段序号左侧；序号使用同宽列并左对齐，有无批注和数量变化均不移动序号。 |
| R31 | 当前片段与正在播放分开 | 选择、播放跟随、查找匹配和手工高亮各有含义；暂停或切换后清除播放装饰，不删除用户标记。 |
| R32 | 原稿只读、编辑稿可修订 | 版本身份可见；项目管理页与编辑器应列出相同的用户版本，名称同步，打开时指向所选版本；版本组以原始稿为上级，同一来源的所有修改稿版本统一缩进一级且彼此平级；无可确认来源的稿件平级单列，层级不随当前激活版本改变；AI 生成结果不等于用户已认可内容。 |
| R33 | 修改痕迹只作比较 | 对照版本、接受或拒绝、隐藏标记是不同操作；比较装饰不进入正文或导出。 |
| R34 | 离线音频仍保留文稿 | 文稿可读、可编辑；无法播放时说明音频问题并提供重新关联路径。 |
| R35 | 播放条只显示已确认的时长 | 新音频或媒体时长变化时先显示 `--:--:--`，确认稳定后再显示总时长并启用进度条跳转；等待时不拿稿件中的旧时长冒充当前媒体时长。播放位置与总时长固定为 `HH:MM:SS`。项目页在音频名称下方常驻显示同格式时长；未打开或未确认时为 `--:--:--`，播放器确认后按音频文件指纹保存，后续修正继续更新。该缓存沿用播放器的确认逻辑，不代表独立文件扫描；内容指纹变化或检测到文件内容改变时不显示旧值。 |

项目页与编辑页的版本菜单共用原始稿归属：新原稿及其派生、复制、AI 生成的修改稿保存稳定来源标识，重命名、排序、移动和恢复不改变来源。旧数据只依据已有且唯一可验证的来源记录补齐，读取时不改写稿件；来源不能确认或原始稿不在当前列表时明确标注，不按名称、引擎或先后顺序猜测。修改稿之间不表现父子层级。默认对照保留用户已选值与记录的比较基准，其余优先选择所属原始稿；已知来源缺失时不自动换成另一份原稿。

编辑页在音频标题行右侧提供图标入口，悬浮与无障碍名称统一为“转录音频”，不新增顶栏操作菜单。点击先打开现有转录配置，已有稿件时明确说明将生成新原始稿且旧稿、修改稿、批注和高亮保留，用户确认后才提交。转录中禁用该入口并说明原因；成功追加独立原始稿，失败或取消不改写旧稿。

外部导入的转录稿，无论独立导入还是关联音频，均保留完整原文件名（含扩展名）作为初始稿件与版本名称，不自动替换为通用修改稿名。使用者主动命名的版本及副本名称优先，已有稿件不做批量改名。

独立导入稿只有被指定为原稿时才显示为只读原稿。内部导入快照可用于来源与时间定位恢复，不作为当前/对照菜单或 MCP 的普通候选版本，也不自动解释为人工编辑偏好的基准。快照用途保留在产品文档，不在版本菜单显示内部机制说明；快照不删除、不改写为用户版本。

批注编辑保留失焦提交，并提供“保存”控件及 Cmd+Enter（macOS）／Ctrl+Enter（Windows）；输入法组合输入期间不提交。“当前片段”和“全部”均可为当前片段新增批注，新增区显示目标片段，切换片段不把草稿带入另一片段；只读时禁止新增和修改。

正文顶部的片段计数右侧仅放“跳转至：”和编号输入框，字号、字体、字重与计数一致，使用现有表面、边框和细焦点样式。按当前版本正文原编号跳转，不随说话人筛选重新编号；输入有效编号后按 Enter 将目标移到阅读区中央并把编辑光标放到段首，长片段优先露出段首。成功清空输入框；无效编号保持输入并用本地化校验提示，输入法确认不触发跳转。目标说话人被隐藏时只恢复该说话人；原稿和 AI 占用稿只定位并聚焦只读正文，不解除保护。跳转不修改正文、版本或音频进度，播放中暂停跟随，可用现有入口恢复。短窗口收起辅助播放提示，保留跳转入口；不增加预览、按钮或常驻帮助。实现见[编号跳转](../frontend/src/components/SegmentJump.tsx)和[编辑器](../frontend/src/App.tsx)。

“合并下一段”遇到不同说话人时使用应用内确认框，默认焦点为“不合并”，Escape 取消；确认后保留当前片段的说话人。等待期间目标稿件、两段内容、顺序或说话人变化时禁止沿用旧确认。隐藏或恢复说话人时按正在阅读的正文位置恢复，不以选中片段或播放器位置代替；阅读片段被隐藏时选择附近仍可见的片段，全部隐藏后恢复时保留此前阅读位置。

实现入口见[片段组件](../frontend/src/components/SegmentItem.tsx)、[播放跟随](../frontend/src/lib/playbackHighlight.ts)、[版本比较](../frontend/src/hooks/useVersionComparison.ts)和[项目存储](../frontend/src/lib/projectStore.ts)。涉及状态重叠时，应检查播放、查找、批注、手工高亮和比较同时出现的场景。

外部文件拖放在所有页面均不得导航或替换应用界面；只有有效且可用的导入区域执行导入。禁用区域和区域外落点不导入，内部排序继续使用自己的拖放处理。应用入口安装[全局文件拖放保护](../frontend/src/lib/fileDropGuard.ts)。

项目内排序从拖动手柄开始，使用移动语义与插入线，不显示文件导入的复制反馈。原始稿及其相关修改稿整体排序；修改稿仅在所属原始稿内排序，拖放和键盘排序均不改变来源归属。场次列表和音频列表的空隙、末尾也接受排序；卡片内的稿件导入框不得拦截排序。外部文件只有到达有效导入区域时才显示复制反馈；同时带有文件标记的内部排序仍优先按排序处理。键盘继续使用 Option／Alt + 上下键，顺序写入失败保留项目原记录。

引用音频读取失败时区分权限需要恢复、原文件缺失、内容改变和其他读取失败；转录稿继续可用。恢复入口沿用音频卡片的文件夹按钮，复制到项目内的音频仍提示检查项目访问。桌面端保存用户明确选择过的资源授权，重启恢复前核对文件身份，失效授权不得访问替换到原路径的其他资源。

最近项目在桌面授权有效时直接打开；失效、缺失或读取失败时显示对应原因，由用户点击“重新选择原项目”恢复，也可取消。恢复后核对项目身份，不能把另一个项目替换到原最近项。

欢迎页和系统菜单共用最近项目列表。桌面端将至多 20 条记录及既有访问描述保存到本地偏好，并回读核对；首次更新沿用旧数据库的列表，旧记录保留。最近列表更新失败不得冒充项目保存失败，也不能静默忽略：在所属项目页提示可继续使用项目，提供重试与关闭；离开项目清除提示，旧项目迟到的结果不得带到新项目。目录授权和项目身份核对继续独立执行。

新建项目独立为名称与保存一步：先填写名称，再打开系统目录选择器，成功写入并核对项目后进入正式项目页，才允许创建场次、导入音频和转录稿。取消选择或保存失败保留名称，不发布未保存的工作区；同名项目不能覆盖。空名称时保存禁用，选择位置及保存期间禁用重复提交、取消和离页操作；输入法组合输入不触发保存。初始焦点在项目名称，保存成功后到“新增场次”。实现见[新建项目](../frontend/src/components/ProjectCreate.tsx)和[项目工作区](../frontend/src/components/ProjectWorkspace.tsx)。

项目回收站位于项目页品牌栏的设置按钮左侧。当前场次标题右侧提供局部删除控件：28px 外框、16px 同族回收站图形，与项目导出按钮外框右边缘对齐；默认保持中性色，悬停以删除色提示。删除场次须确认范围，默认焦点为取消；场次及其中的音频、原稿、全部版本和批注一起进入回收站，恢复时整场恢复。删除前已经在回收站的材料继续保持删除状态，随所属场次恢复后仍可在回收站单独恢复。删除或恢复不改写材料文件，不删除外部引用原文件；永久清空另有明确确认。存在 AI 编辑保护或其他窗口正在编辑时不得删除。删除最后一个场次后，项目及品牌栏回收站仍可访问。

## 外部 AI 连接

本机就绪不代表 ChatGPT 隧道就绪。ChatGPT 配置下持续显示隧道连接、就绪、自动重连或配置不可用状态；总开关开启时保留“重新连接”入口。自动恢复只重建连接，不重新提交编辑或保存。关闭总开关停止恢复，保留配置。

MCP 总开关关闭时，三个客户端的配置区域统一变灰且不能操作，包括软件选择、输入、添加、导出、删除、链接及折叠帮助；启用开关仍可用，重新启用保留配置与选择。ChatGPT 配置失败在保存操作下方持续显示具体错误，不自动聚焦或滚动；取消或重新选择程序后可恢复，不把失败显示为成功。

ChatGPT 的“删除配置”左侧提供“修改配置”，与卡内同名入口共用编辑、保存和取消状态。所选 AI 软件的“删除 ChatGPT／Claude／WorkBuddy 连接配置”使用危险色的文字按钮，与启停分开。确认框明确软件名称与本机配置／凭据范围，先聚焦取消，Esc 只取消最上层确认，关闭后回到触发按钮；删除成功后该按钮消失，焦点回到软件选择框。删除期间锁定操作；进行中的该软件请求先结束再删除，失败留在确认框并可重试，不回显原始错误或凭据。删除保留其他软件、项目、稿件和下载的连接程序；远端隧道／密钥撤销及其他软件插件卸载在对应软件／网页处理。成功重置 ChatGPT 表单并提供重新添加路径，不重启其他软件的连接。

editing”。窄窗允许按钮换行，待提交正文在提示内限高滚动，不遮挡稿件。只有磁盘保存成功才显示“已保存”。任务和待提交结果保存在本机当前稿件内，重开后可继续；暂停、结束和重读有明确动作，结束不回滚已保存批次。开始前的人工修改继续保留；编辑期间目标版本暂时只读；外部文件变化造成冲突时暂停该批并保留双方结果。每批支持本会话内普通撤销，恢复任务不自动启动外部 AI，也不扩大到其他项目；同项目后台任务按固定稿件与版本 ID 恢复，不要求先打开它。

单个 AI 续写任务日志损坏时，在现有续写提示区域说明原文件保留、其他完好任务仍可使用；不隐藏完好任务的操作，不自动修改或删除损坏记录。简中、繁中和英文使用相同的提示位置及错误文字样式。

AI 编辑提示统一占用顶栏下方“已载入转录稿”的状态栏位置；有 AI 提示时不重复显示载入反馈，不在标题或正文上方另放进度栏。进行中左侧细线锁及危险色文字，右侧描边“结束编辑”；目标名称和实际处理／已保存片段计数紧随说明。窄窗文字可换行，按钮完整可见，正文滚动不带走提示。只保护正在被 AI 编辑的稿件及精确版本：人工及其他 AI 不能修改；暂停、等待、参数错误、断线均不得自动解除保护，不使用“解锁／可编辑”的说明。用户点“结束编辑”立即撤销后续写入并收起提示；若已有磁盘保存正在执行，先显示“正在结束…”并禁止重复点击，保存确认后再收起。确认完成后显示完成和真实保存计数，并提供有可访问名称的“×”关闭控件；关闭不删除回执。每个目标只展示最新一次任务，完成或关闭后不重新带出旧失败提示。后台任务明确点名目标，其他稿件仍可编辑。只读侧栏区分 AI 占用与原稿只读。结束或关闭后焦点回到正文，未确认保存不得计入已保存。


AI 编辑的“结束编辑”旁说明已保存内容保留、之后继续需核对剩余范围并新建任务；不增加重复确认框。暂停可恢复，结束永久取消旧任务，不将两者混用。界面不声称新任务会自动开始；等待保存确认的结束状态仍保持禁用与原有焦点行为。三语说明放在现有状态栏文字区域，沿用正文说明字号与可换行布局。MCP 服务目录、桌面连接、外部客户端可见工具和写入权限分别陈述，不能以连接就绪承诺客户端已取得写入工具。
